# Lesson 2 — Draft a grounded script and storyboard

## Goal

Create a short experience whose spoken wording remains traceable to approved content.

## Duration

25 minutes.

## Audience

Onboarding lead, content owner, SME, accessibility lead, communications/brand representative, and facilitator.

## Prep

Use the approved claims from Lesson 1 and open `../accelerator/sample-data/storyboard-script.json`, `transcript.txt`, and `accessible-fallback.html` as structural examples.

## Timed activity

| Time | Activity |
| --- | --- |
| 0–5 min | Set a single learning outcome and the human help route for questions or exceptions. |
| 5–14 min | Draft one idea per segment. Link each spoken statement to its claim ID and source reference; do not paraphrase an approved claim until its owner approves that wording. |
| 14–20 min | Add visual intent, on-screen text, opening disclosure, captions, transcript, language plan, and non-avatar alternative for every segment. |
| 20–25 min | Read the transcript and fallback without the avatar. Check that the experience still works and routes uncertainty to a person. |

## Artifact

A versioned script/storyboard, transcript, and accessible fallback plan.

## Expected output

Each segment has an ID, exact spoken wording, approved-claim link, source reference, visual intent, and accessibility references. The opening clearly states that the presenter is avatar-generated or AI-assisted.

## Validation

Compare every spoken line with the linked claim. The supplied local mock rejects a line that is not an exact approved wording. Confirm that the transcript contains every line and that the fallback communicates the same actions.

## Debrief

Could an employee complete the onboarding task with only the transcript or HTML page? If not, the channel is not yet inclusive.

## Next decision

Submit the script/storyboard and accessibility plan to the approval gate in Lesson 3.
