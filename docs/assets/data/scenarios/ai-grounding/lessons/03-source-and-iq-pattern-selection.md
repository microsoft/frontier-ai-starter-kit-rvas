# Lesson 3 — Source and IQ pattern selection

## Goal

Select a governed context pattern for the bounded decision and document why alternatives were rejected.

## Duration

40 minutes.

## Audience

Business owner, platform architect, source owner, security reviewer, and facilitator.

## Preparation

Bring the Lesson 1 boundary, Lesson 2 decision map, current source inventory, and a capability-verification owner. Do not assume preview service behavior from this scenario.

## Timed activity

| Time | Facilitation step |
|---|---|
| 0–10 min | List candidate sources with owner, update cadence, permissions, and citation expectation. |
| 10–20 min | Compare Copilot Studio + SharePoint, Foundry IQ, Fabric IQ, Work IQ, and Web IQ against the decision map. |
| 20–30 min | Score the two best fits for source authority, permissions, freshness, operational fit, and evidence. |
| 30–40 min | Record the leading option, rejected alternative, assumptions, and documentation checks required before implementation. |

## Artifact

A pattern decision record with candidate sources, selected pattern, rejected alternative, access model, freshness expectation, operating owner, and verification tasks.

## Expected output

For the fixture, approved internal policy documents can support a governed document-grounding pilot; confidential supervisor procedure remains role-limited. No product is selected until current capabilities are verified.

## Validation

The record names an owner for every source, states permission behavior, and gives a specific reason the rejected option does not fit the first pilot.

## Debrief

Ask: “Did we choose a product before proving the experience need?” If yes, return to the decision map rather than rationalizing the architecture.

## Next decision

Define the golden cases, citations, and refusal expectations that will prove the selected pattern.
