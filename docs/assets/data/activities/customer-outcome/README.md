
# Customer outcome record

Use this as a working record beside the [Decision Explorer]({{ '/decision-explorer.html' | relative_url }}).
It is intentionally small: capture only what the customer needs to decide whether to demonstrate,
test, pilot, harden, or stop.

| Field | Capture |
|---|---|
| Customer outcome | What becomes faster, safer, cheaper, or more reliable? |
| Target users and access | Who benefits, who must not see it, and what access boundary applies? |
| Current context | Which documents, SharePoint sites, data products, approved content, or systems matter? Who owns them? |
| Starting environment | Is this a clean demo subscription, an existing Azure/Foundry foundation, or Microsoft 365 / Copilot Studio? |
| Ownership model | Who owns the business result, technical build, source changes, and operations? |
| Safety boundary | What must be refused, reviewed, redacted, or never automated? |
| Golden dataset | Which representative routine, edge, access-denied, and high-impact cases will prove the result? |
| First demo | What short interaction proves the outcome, and what decision should follow it? |
