# Customer lens · Governed data copilot

Use [Governed Data Copilot](../activities/extra-governed-data-copilot) when operational insight
needs explicit field allowlists, requester access rules, query validation, provenance, and review.
The session is not a shortcut around data governance: record the data owner and denial/escalation
path before enabling the connection.
