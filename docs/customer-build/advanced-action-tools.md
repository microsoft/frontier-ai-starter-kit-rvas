# Customer lens · Governed action

Use [Action Tools](../activities/advanced-action-tools) as the canonical session when the outcome
changes a system, creates work, or triggers a handoff. Define the requester, approver, side effect,
denial path, audit evidence, and safe retry before connecting the tool.

An action is not required for knowledge, data, or voice-only paths. Use it only when a governed
workflow is the customer proof point.
