# Customer lens · Visual multimodal

Use [Visual Multimodal](../activities/extra-visual-multimodal) as the canonical session when a
safe image is necessary to complete the task. Define allowed image classes, prohibited content,
uncertainty behavior, human reviewer, and an auditable result schema. Do not use customer photos or
other sensitive images for a session demo without explicit approval.
