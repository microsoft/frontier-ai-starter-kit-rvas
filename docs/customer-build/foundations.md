# Customer lens · Agent baseline

Use [Foundations](../activities/foundations) as the canonical session. Complete Steps 1-3 for every
customer path: provision the environment, compare models on scenario prompts, and define the agent
scope and guardrails. Complete Step 4 only when document-grounded answers are part of the selected
path.

Record the model trade-off, target users, agent boundaries, approved inputs, and the evidence that
proves the baseline is ready. Then return to [Customer Build](../customer-build) and select the next
route session.
