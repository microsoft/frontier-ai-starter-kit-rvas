## 2026-06-23 — Customer Activity-Forge Skill

**Author:** Danny (Lead & Content Architect)  
**Date:** 2026-06-23  
**Status:** Approved; merged from decision inbox

### Summary

A new **full working Copilot CLI skill** has been authored at
`.github/skills/customer-activity-forge/SKILL.md`. This is the centrepiece tool for
session participants who arrive with a customer name and industry but no idea what to build.

### What it does

When invoked inside Copilot, the skill:

1. Collects `customer_name` (required), `industry` (required), and optionally
   `region_or_segment` and `known_pain_points`.
2. Runs a structured **Research phase** using `web_search` and `web_fetch` against public
   sources only (company site, investor relations, earnings transcripts, press releases,
   industry reports). Every claim is cited; unverifiable facts are flagged ⚠️.
3. Generates **~10 ranked AI-application ideas** each with title, description, target user,
   business outcome, tier/tech mapping, effort tag, industry-fit rationale (cited), and
   required knowledge sources.
4. Calibrates difficulty to the event window via explicit guardrails.
5. Outputs: ranked summary table → per-idea detail blocks → Recommended top 3 →
   Customer Outcome Canvas Pre-work pre-fill for the top idea.

### Calibration rules (canonical — use in all related content)

**The sweet spot is: grounded agent + one governed action.**

| Tag | Definition |
|---|---|
| `Starter` | Foundations only. Grounded FAQ agent, no actions. ~2 hr for a first-timer. |
| `Core` | Foundations + one Advanced activity (typically Action Tools or Evaluation & Red Teaming). Full event-day build. **The default recommendation for most teams.** |
| `Stretch` | Three or more tiers, or Capstone/MAF orchestration. Needs strong Foundations prerequisite. |

Guardrails baked into the skill:
- Not too trivial: every idea must use domain-specific knowledge, not a generic FAQ bot.
- Not over-common: at least one Foundry capability beyond a plain agent.
- Not over-complex: cap Core ideas at one action + one knowledge source.
- Data-ready check: every idea names a plausible knowledge source; Northfield corpus is the
  explicit fallback when real customer data is not available on event day.

### Tier/tech name mapping (exact labels — canonical)

All idea output uses these labels (matching `docs/index.md` and `activities/` folder names):

- **Foundations** · **Action Tools** · **Evaluation & Red Teaming** · **Tracing & Observability**
  · **Deploy as Hosted Agent** · **Capstone** · Extra — Fabric IQ · Extra — Voice Live
  · Extra — Magentic Workflows · Extra — Build a UI

## 2026-06-23 — Outcome-First Session Positioning

**Author:** Rusty (Curriculum Designer)  
**Date:** 2026-06-23  
**Status:** Approved; implemented and merged from decision inbox

### Decision

Reframe the session so **Customer Build / Bring-Your-Own-Outcome is the primary motion** and
**Upskill via Northfield University is the secondary / fallback path**.

Previously the two modes were presented as co-equal. Going forward:

| Mode | Position | Use when |
|------|----------|----------|
| **Customer Build Mode** | Primary | Team has a customer, account, business scenario, or an idea generated by Customer Activity-Forge |
| **Upskill Mode (Northfield)** | Secondary / fallback | Team is new to Foundry and has no customer scenario, or wants a pure guided learning path |

The three-tier structure (Foundations → Advanced → Capstone) is unchanged. Northfield is NOT removed;
it remains the known-good reference path and the safe fallback when a team has no scenario.

### On-ramp: Customer Activity-Forge

A new Copilot CLI skill is being authored at `.github/skills/customer-activity-forge/`. It is the
on-ramp for teams that want to build something real but don't have an idea yet:

1. Provide a **customer name** and **industry**.
2. The skill researches public documentation (company site, investor relations / annual reports,
   industry trends & activities).
3. It generates **~10 right-sized, buildable Microsoft Foundry AI application ideas**, each with an
   industry rationale and a suggested tier mapping.
4. The team picks one idea and fills in the **Customer Outcome Canvas** (`docs/customer-outcome.md`)
   using the output.

Once the canvas is complete, the team proceeds as Customer Build Mode — same tiers, same checkpoints,
real outcome.

### Rationale

Customer engagements and account workshops are the highest-value delivery context for this session.
Leading with "bring your outcome" signals to participants and facilitators that the goal is a real
prototype, not a tutorial completion. The Northfield path remains fully intact as a guided on-ramp
for learners who need it — it is repositioned as a scaffold, not the destination.
