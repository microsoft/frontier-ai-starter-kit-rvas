# Lesson 2 — Decision explorer context

## Goal

Turn the selected outcome into a decision journey with only the context and evidence needed at each step.

## Duration

35 minutes.

## Audience

Business owner, frontline practitioners, source owner, and facilitator.

## Preparation

Bring the completed Lesson 1 canvas, one normal case, one exception, and one request the experience must decline.

## Timed activity

| Time | Facilitation step |
|---|---|
| 0–5 min | Restate the user, trigger, action, and non-goal from Lesson 1. |
| 5–15 min | Walk a normal case from trigger to action; mark the evidence required at each step. |
| 15–25 min | Walk an exception and an access-denied case; mark the required handoff. |
| 25–35 min | Classify each fact as document knowledge, operational record, work context, or public information. |

## Artifact

A decision map that lists trigger, required facts, authoritative source, permitted role, response action, citation need, and stop condition.

## Expected output

The Northstar map requires policy evidence for an in-window return, exception guidance for transit damage, and a supervisor handoff for day 31–45 hardship review.

## Validation

Each required fact changes a named action; each action names an authority; “do not answer” cases explicitly identify an owner or queue.

## Debrief

Ask: “Which facts would merely sound helpful but do not change the decision?” Remove them rather than expanding the corpus.

## Next decision

Select the source and context pattern that can supply the mapped evidence while preserving the access boundary.
